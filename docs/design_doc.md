# Project Title

Hospital Management System

---

## Problem Statement

Many hospitals still rely on manual paperwork or multiple disconnected systems to manage patient records, doctor information, appointments, prescriptions, and billing. This approach often leads to misplaced records, appointment scheduling conflicts, increased paperwork, and delays in accessing important medical information.

The objective of this project is to develop a centralized Hospital Management System that digitizes these operations, improves efficiency, and provides secure access to hospital data.

---

## Proposed Solution

The proposed solution is a Hospital Management System developed using Python and PostgreSQL. The system will provide a centralized platform where hospital staff can manage patients, doctors, appointments, prescriptions, and billing records.

The application will reduce manual work by storing all hospital information in a PostgreSQL database while Python handles the business logic and communication between the user interface and the database.

---

- Appointment booking should work correctly.
